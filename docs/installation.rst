Installation
============

Prerequisites
--------------

- Access to the lab HPC cluster, with ``singularity`` and ``jq`` on ``PATH``.
- Python 3 — used by ``setup/setup.py`` and ``setup/add_tools.py`` to resolve per-project
  config, no separate install needed.

Clone the repo
----------------

.. code-block:: bash

   git clone https://github.com/dpeerlab/dangerous_claude.git
   cd dangerous_claude

No package to install — everything runs from the checkout. See :doc:`quickstart` next.
